# 🎰 Bingo Profissional v4

Um sistema profissional de sorteio e marcação de bingo, desenvolvido por **Manoel Santana** e **Fábio Augusto**.

## 📱 Acessar o site

🌐 **[Clique aqui para abrir o site](https://fabio1doflamengo.github.io/Bingo.simples/)**

## 🎯 Funcionalidades

✅ **Grade de números** - 75 números organizados em 5 colunas (B-I-N-G-O)  
✅ **Marcação rápida** - Digite o número e pressione Enter  
✅ **Destaque gigante** - Exibe o número sorteado em tela cheia  
✅ **Fullscreen** - Modo tela cheia (⛶)  
✅ **Menu de modos** - BINGUINHO, BINGÃO, BINGO CORRIDO  
✅ **Desmarcar** - Duplo clique na célula para desmarcar  
✅ **Resetar** - Limpa todas as marcações  
✅ **PWA** - Funciona offline com Progressive Web App  

## 🚀 Como usar

1. Abra o site
2. Digite o número sorteado (1-75) no campo de entrada
3. Pressione **Enter** para marcar
4. Use o menu (•) para mudar o modo de bingo
5. Clique em **Fullscreen** para tela cheia
6. Use **Resetar** para limpar tudo

## 🔧 Como instalar localmente

```bash
git clone https://github.com/fabio1doflamengo/Bingo.simples.git
cd Bingo.simples
# Abra index.html no navegador
```

- `manifest.json` - Configuração PWA
